# Project Resume Guide

This file is a short navigation summary. For actual drafting, read the task-specific reference files directly.

## Read Order

1. `output_mode_rules.md`：确定直接简历或亮点素材库模式，并按项目规模推荐条目数。
2. `resume_quality_rules.md`：判断什么内容值得写进技术简历。
3. `role_focus_map.md`：根据 `{目标岗位方向}` 调整重点。
4. `project_signal_patterns.md`：从代码和文档中识别简历信号。
5. 直接简历模式读取 `resume_bullet_patterns.md` 和 `resume_style_rules.md`。
6. 项目亮点素材库模式读取 `highlight_library_format.md`。
7. `weak_vs_strong_bullets.md`：把弱表达改成强表达。
8. `resume_risk_rules.md`：最终输出前检查虚写、夸大和泄密风险。

## Core Principle

Do not convert README content directly into resume bullets. First choose the downstream artifact and item count, identify resume-worthy technical signals, verify contribution boundaries, then draft either concise resume bullets or a detailed reusable highlight library.
